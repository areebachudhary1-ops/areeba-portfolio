# Areeba Asghar — Portfolio

A static multi-page HTML/CSS/JavaScript portfolio connected to Supabase.

- `index.html`, `about.html`, `portfolio.html`, `what-i-do.html`, `experience.html`, `contact.html`: public pages
- `admin.html`: private content management interface (requires a Supabase Auth account registered in `public.admin_users`)
- `js/data.js`: local starter content and offline fallback
- `js/supabase-config.js`: configure your own Supabase project
- `backend/supabase.sql`: database, row-level security, and storage setup
- `backend/seed-portfolio.sql`: starter portfolio data
- `backend/README.md`: complete Supabase, GitHub, and Vercel deployment instructions

Start with `backend/README.md`. Add your own Supabase URL/key before testing the live data connection. Add your contact details and your own photo through the Admin Panel.
